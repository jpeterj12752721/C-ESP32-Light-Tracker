# C-ESP32-Light-Tracker

•	Designed and prototyped a single-axis solar tracking device utilizing an ESP32 microcontroller, dual photoresistors, and servo actuator.
•	Implemented a custom PID controller in C++ to process sensor input and output smooth PWM positioning signals, avoiding system oscillation and motor overshoot. 
•	Fine-tuned physical photoresistor configurations and calibrated differential sensing thresholds to maximize light-intensity tracking accuracy.
•	Optimized ESP32 polling rate and operating frequency to balance real-time responsiveness with minimal power consumption and jitter.
